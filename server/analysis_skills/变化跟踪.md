历史来自同一作者、且发布时间早于当前素材。只有对象、期限和作用层面可比较时才生成change。
产业长期看好和短期谨慎可以同时成立，不能自动标成转向；股价上涨也不等于产业论点被证实。
change.previous_id必须来自提供的历史id。kind只能是新增论据、条件变化、期限变化、立场变化、表述变化、延续判断。
只有明确相反的看多与看空判断才标立场变化；中性或不明确的表达变得更具体，应标表述变化，不能直接认定作者转向。
summary说明改变了什么，以及前后比较的限制。无可比历史填null。不同公司、不同产业环节或完全不同时间范围不要强行比较。
变化记录必须保留前后判断，不改写或删除过去的版本。真假核验与观点变化分别记录。
